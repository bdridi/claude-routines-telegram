# Digest envoyé — 2026-10-21

## Message

🗞 Veille — mercredi 21 octobre

🤖 IA / Agents
• Anti-Persistence : l'agent qui oublie ses leçons fait moins d'erreurs — Un agent qui résume ses échecs passés en règles risque de mémoriser l'erreur elle-même, qui revient alors sur les tâches suivantes. Anti-Persistence garde les trajectoires brutes et jette les résumés après usage, avec un bandit contextuel pour choisir comment s'en servir : +6 à +11 points de réussite sur 7 des 9 combinaisons testées, et moins d'appels LLM que les mémoires classiques.

🏗 Archi
• Pinterest finalise ses partitions CDC avec des watermarks de temps d'événement — En CDC continu (MySQL/TiDB → Kafka → Flink → Iceberg), rien ne signale naturellement qu'une partition est complète, contrairement à la fin d'un job batch. Pinterest calcule à chaque commit Iceberg un watermark monotone (minimum des temps d'événement, via des t-digests de quelques centaines d'octets) publié comme propriété de table — les jobs aval le lisent directement, sans service de coordination séparé.

🧱 System design
• Une faille NetScaler s'exécute avant toute vérification d'identité — CVE-2026-88771, exploitée activement, permet d'exécuter des commandes sans authentification sur les passerelles Citrix NetScaler. La leçon dépasse ce produit : exposer un portail d'accès directement sur Internet est une décision de conception, pas un défaut hérité — il faut une politique d'accès indépendante devant le code sensible, qui ne se contourne pas par l'origine directe.
• Huit certificats eMudhra compromis, par clés privées faibles — Des clés privées de certificats intermédiaires compromises permettent de forger un certificat valide pour n'importe quel domaine. La leçon généralisable : un magasin de confiance ne peut pas être une liste statique — propager un correctif de confiance est un problème de graphe de dépendances, une bibliothèque à jour ne garantit pas une politique de vérification corrigée.

🛠 Dev
• TypeScript 7.1 passe en bêta, avec des gains de compilation massifs — Le compilateur natif gagne les attributs d'import pour modules déclarés et les "source phase imports" pour WebAssembly, et stabilise la cible es2026. Surtout : +12 à +28% de vitesse selon les projets testés par rapport à 7.0, jusqu'à ~1,9x plus rapide et -50% de mémoire sur un gros projet réel (mui-docs).
