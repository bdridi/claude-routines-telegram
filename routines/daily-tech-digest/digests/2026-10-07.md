# Digest envoyé — 2026-10-07

## Message

🗞 Veille — mercredi 7 octobre

🤖 IA / Agents
• Mistral Large 4, un modèle souverain à mille milliards de paramètres — « Le Chonk » : 1T de paramètres dont seulement 49B actifs, entraîné sur 3800 GPU Grace Blackwell en Europe. Déployable en interne sans garde-fous imposés par le fournisseur — l'argument est la souveraineté autant que les benchmarks (82% sur la reproduction de vulnérabilités, devant GPT-6-Astra en grounding visuel).
• EmbeddingGemma 2 : l'embedding multimodal qui tient sur un téléphone — 740M de paramètres modulaires (270M pour le texte seul), espace d'embedding unifié texte/image/audio/vidéo, tronquable de 768 à 128 dimensions via Matryoshka. Tourne sur un Pixel avec 191 Mo de RAM — du RAG multimodal entièrement on-device, sans aller-retour serveur.
• La Decisions API d'OpenAI passe en bêta publique — Un endpoint dédié qui répond à trois formats de questions (probabilité, choix fermé, score) sans passer par un LLM généraliste — 10x plus rapide que l'API Responses, facturé uniquement en entrée. Pour un agent qui doit juste router ou prioriser, ça évite le coût et la latence d'une génération de texte complète.

🏗 Archi
• GitHub découple le stockage Git du calcul pour tenir la charge des agents — Le trafic Git a doublé en un an (473 milliards d'événements/mois), les pushes x4,9 — les agents commitent après presque chaque action. Plutôt qu'ajouter des réplicas, qui ralentissent les écritures, GitHub sépare la mise à jour des références du stockage des objets : jusqu'à 35x plus de débit en écriture, lecture qui scale seule.

🧱 System design
• La clé racine de tout l'Internet change le 11 octobre — Deuxième rotation de la clé de signature racine DNSSEC (KSK) de l'histoire : si les résolveurs validants ne font pas confiance à la nouvelle clé à temps, des sites entiers deviennent injoignables. Un protocole de test (RFC 8509, sentinelles de confiance) permet de vérifier en amont si son résolveur est prêt.
• Un accélérateur IA conçu de bout en bout par des agents — Sur un FPGA Xilinx Kintex-7, OpenTPU fait tourner un modèle de 230M de paramètres à 85,8 tokens/s avec 82-85% de la bande passante DRAM théorique — chaque mouvement de donnée est une instruction tracée, simulateur et matériel produisent des résultats identiques au bit. Jusqu'où des agents peuvent pousser la conception matérielle, pas seulement logicielle.

🛠 Dev
• Python 3.15 : des gains minces hors free-threading — Benchmarks Fibonacci et tri à bulles de 3.10 à 3.15 : le gain single-thread face à 3.14 est marginal, le GIL limite toujours le multi-thread standard. Seules la variante free-threading (4,5x sur du calcul parallèle) et le JIT expérimental (1,2-1,28x) changent vraiment la donne — pas encore pour la prod.
