# Digest envoyé — 2026-09-17

## Message

🗞 Veille — jeudi 17 septembre

🤖 IA / Agents
• HarnessTax : le harnais coûte cher, pas la réussite — Sur SWE-bench Lite et Terminal-Bench 2.0, changer de harnais (Claude Code, Codex CLI, Pi) affecte à peine le taux de réussite d'un même modèle — mais jusqu'à 5x son coût. Pi, un harnais minimaliste à quatre outils (read/write/edit/bash), atteint la frontière de Pareto : Claude Code coûte 2x plus cher que Pi pour seulement +1% de réussite.

🏗 Archi
• Le harnais qu'on construit devient obsolète aussi vite qu'on le construit — Robert "Uncle Bob" Martin raconte avoir développé un harnais de contrôle pour ses agents — devenu inutile le temps qu'il le termine, les modèles ayant assez progressé entre-temps. Fowler en tire un principe : concevoir les garde-fous pour la super-persévérance autant que pour la super-intelligence.
• Dropbox transforme son service de preview en plateforme de contenu pour l'IA — Riviera est passé d'un simple preview de fichiers à une plateforme universelle : 300+ formats, transformations composables via un modèle de plugins découplé de l'orchestration, cache partagé entre opérations IA. ~2,5 milliards de requêtes/jour.

🧱 System design
• Cloudflare traque le JS malveillant qu'aucun scanner ne voit — Un réseau de neurones sur graphe analyse le JavaScript comme du code structuré, avec validation secondaire par un LLM pour réduire les faux positifs. Quatre campagnes de fraude détectées en trafic réel — sept des huit charges utiles étaient absentes de VirusTotal.
• Un modèle de 4B entraîné par RL bat le planificateur de requêtes de Postgres — Distillation d'un modèle frontière puis RL pour générer des hints SQL : 1,81x de gain de vitesse en moyenne géométrique sur 113 requêtes à jointures multiples, -44,7% de temps cumulé, pour 1200$ d'entraînement.

🛠 Dev
• GitHub porte le runtime Copilot en Rust — 830 000 lignes, un développeur, quatre mois — Migration incrémentale composant par composant (128 PR), interop temporaire via napi-rs puis surface C ABI exposée à six SDK. L'essentiel du code a été généré par Copilot, l'humain se concentrant sur l'architecture — gains de performance de plusieurs ordres de grandeur au démarrage.
• Go 1.27 accélère l'allocation des petits objets de 20 à 30% — Des variantes de l'allocateur spécialisées par classe de taille (jusqu'à 80 octets) évitent le calcul générique et inlinent le nettoyage mémoire en assembleur, appelées directement quand la taille est connue à la compilation. Gain concentré sur les allocations de 16-24 octets (strings, interfaces, slices).

📡 Radar — InfoQ AI, ML and Data Engineering Trends Report (édition 2025)
• MLOps — Early Majority
  Passé cette année de l'adoption précoce à la majorité précoce, aux côtés des Vector DBs et Synthetic Data : le rapport le classe comme pratique devenue mature et largement répandue, plus un chantier réservé aux pionniers.
• Distributed computation (Storm) — Late Majority
  Le rapport range Apache Storm, l'un des premiers frameworks de calcul distribué temps réel, dans sa catégorie la plus mûre — "pleinement adopté, partie intégrante des patterns d'architecture". Un classement à contre-courant : la plupart des stacks modernes ont depuis basculé vers Flink ou Kafka Streams.
