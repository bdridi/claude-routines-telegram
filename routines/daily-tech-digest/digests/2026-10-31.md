## Message

🗞 Veille — samedi 31 octobre

🤖 IA / Agents
• Datadog Scout, un modèle spécialisé pour les investigations SRE
  Entraîné par renforcement sur des simulations d'incidents, il enquête sur une alerte avant même qu'un ingénieur ne réponde — 3 à 8 fois moins cher qu'un modèle généraliste à score équivalent. Récompenser seulement la réponse finale le faisait arrêter trop tôt : il a fallu aussi récompenser l'exploration et les preuves.

🏗 Archi
• Le paradoxe de la supervision : l'IA mange les tâches qui forment les ingénieurs
  Alasdair Allan (QCon) montre que l'IA retire les tâches simples qui formaient les juniors sans les remplacer, alors que superviser du code généré demande les compétences que cet usage atrophie. Pistes : documenter les décisions d'architecture, et limiter le rayon d'impact des permissions — après l'incident Kiro chez AWS où un agent a recréé un environnement de prod.
• Microsoft retire Azure Deployment Environments sans remplacement
  Le service s'arrête en février 2027, Dev Box suit en 2028, sans outil de migration ni équivalent. Rappel pour qui dépend d'un cloud managé : inventorier tôt ses dépendances et garder l'infrastructure en code.

🧱 System design
• Netflix traite la fiabilité GPU comme un problème de systèmes distribués
  Sur des jobs de semaines sur des centaines de GPU, Netflix empile santé par couches, échec par défaut et remédiation progressive — nœuds dispo à 99,95%, jobs réussis passés de 98% à plus de 99,5%. À cette échelle, on ne garde plus chaque machine disponible, on rend sa récupération moins coûteuse.
• Titus isole certaines tâches sur leur propre instance EC2
  Pour le streaming à fort débit, le noyau partagé ne répartit pas équitablement cache et bande passante : une tâche bruyante coûte parfois plusieurs minutes de reprise à ses voisines. Isolation de performance et de sécurité sont deux problèmes distincts — ce mode cible le bruit entre équipes de confiance, pas le code non fiable.
• DoorDash précalcule les listes de courses, de 16s à 2s
  Plutôt que de faire raisonner un LLM à chaque requête, DoorDash précalcule par lots les achats récurrents probables et ne résout le catalogue qu'à la demande ; l'agent n'intervient que si un vrai raisonnement s'impose. La question clé n'est pas d'ajouter du raisonnement, mais de décider ce qui se calcule à l'avance.

🛠 Dev
• Porte dérobée dans l'extension Claude Code du Cursor Marketplace
  Les versions 2.1.312 et 2.1.313 de l'extension VS Code officielle, distribuées via le Cursor Marketplace, installaient une clé SSH et un tunnel inverse persistant dès le chargement du fichier. Désinstaller ne suffit pas : une extension « officielle » peut être compromise sur une marketplace tierce.
• sanstun, une implémentation WireGuard sans-IO et parallélisable en Rust
  Firezone remplace son fork de boringtun par cette réécriture qui sépare la logique d'état des entrées-sorties, ce qui simplifie les tests et permet de simuler tout le système de façon déterministe. Le chiffrement coûteux part sur un thread séparé, l'état reste mono-thread sans verrou.
