# Digest envoyé — 2026-11-05

## Message

🗞 Veille — jeudi 5 novembre

🤖 IA / Agents
• Ripple-65B Preview, le nouveau SOTA ouvert du codage agentique, dix fois moins cher à entraîner
  Ricursive Intelligence publie en open-weight un modèle dense de 65B (80 couches, contexte 1M tokens) qui devance tous les modèles ouverts en codage agentique (TerminalBench 2.1 : 80,5, devant Reflection Beam 501B et Meta Muse Spark 816B). R&D à 32M$, dix fois moins que le précédent SOTA ouvert, avec 70x moins de rollouts RL — sans données de posttraining achetées, seulement du synthétique.

🏗 Archi
• Inkitt automatise les PR à faible risque avec un orchestrateur d'agents reprenable
  Un orchestrateur événementiel coordonne des conteneurs d'agents éphémères ; chaque exécution persiste son état en base pour pouvoir reprendre, et seul l'orchestrateur détient les identifiants vers l'extérieur. Garde-fous stricts (migrations, auth, paiements exclus ; deux essais max par étape ; merge toujours humain) — leur lead technique résume : « le modèle était la partie facile », le dur, c'est l'idempotence et les permissions.

🧱 System design
• Cloudflare donne aux sites de quoi voir et piloter les agents personnels qui les visitent
  Nouvelle catégorie « Personal Assistants » dans l'analyse de trafic et politiques par agent (Allow / Block sur pages pub / Block), pour distinguer un agent utile d'un risque plutôt que tout bloquer. Une protection anti-fraude en accès anticipé relie chaque compte aux agents ayant agi pour lui, pour contenir une prise de contrôle sans bannir l'agent pour tout le monde.

🛠 Dev
• Go publie encoding/json/v2, des défauts enfin stricts pour le JSON
  Go 1.27 stabilise jsontext et json/v2, qui corrigent les angles morts du package historique (UTF-8 invalide accepté, noms dupliqués tolérés, nil sérialisé en null) par des défauts stricts. v1 reste supporté indéfiniment et tourne désormais sur v2 — la promesse de compatibilité Go 1 empêchait de corriger ça en place, d'où une nouvelle version plutôt qu'un correctif.

📡 Radar — InfoQ AI/ML/Data Engineering Trends 2026
• AI Agents / Agent Orchestration — Early Adopters
  Le rapport documente le passage de l'IA qu'on interroge à l'IA à qui on délègue — agent personnel, puis équipe, puis organisation entière. Les systèmes multi-agents gagnent du terrain sur l'agent unique : Early Adopters marque la phase où on apprend à les faire tourner, après celle où on apprenait à les construire.
• Context Engineering — Early Majority
  Pour un des auteurs du rapport, la pollution du contexte est « le plus gros problème » — agrandir la fenêtre ne le résout pas, ça rend l'agent plus lent, plus cher et moins fiable. Le rapport recommande de gérer sources, permissions et compression plutôt que de tout faire entrer.
• Spec-Driven Development / AI Software Factories — Innovators
  Les développeurs se concentrent sur les specs, l'IA automatise design et code jusqu'à la PR — certaines entreprises créent des équipes « software factory » dédiées. Classé en Innovators alors qu'un des auteurs dit lui-même pratiquer ça depuis 4-5 ans sans plus en entendre parler : l'étiquette a peut-être du retard sur l'usage réel.
