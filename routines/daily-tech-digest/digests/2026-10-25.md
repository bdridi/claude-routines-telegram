## Message

🗞 Veille — dimanche 25 octobre

🤖 IA / Agents
• OpenDS : plus d'outils ne garantit pas une meilleure réponse
  Benchmark de recherche web profonde multi-sauts (vidéo, audio, texte, GUI) où chaque enquête doit recouper plusieurs sources avant de répondre. Sur douze modèles de pointe, le meilleur plafonne à 39% de précision — et multiplier les appels d'outils ou le temps de recherche n'améliore pas forcément la réponse, un repère utile pour calibrer le budget d'outils d'un agent de recherche plutôt que de le laisser tourner plus longtemps.

🏗 Archi
• Google sépare le garde-fou indicatif de la contrainte réelle pour ses agents de données
  Le Data Agent Kit de Google passe en disponibilité générale avec deux niveaux de garde-fou distincts : une skill consultative qui demande confirmation avant une opération irréversible (DROP, DELETE sans WHERE), et une politique IAM contraignante qui bloque tout outil MCP non lecture-seule, quel que soit le comportement de l'agent. La leçon dépasse l'annonce produit : une consigne dans une skill reste indicative, seule l'infrastructure d'identité garantit vraiment quelque chose.

🧱 System design
• Cloudflare confine ses clés racines à une région plutôt que de chiffrer plus fort
  Le chiffré circule librement sur le réseau mondial via Quicksilver, mais seule une clé racine symétrique qui ne quitte jamais sa région — attestée par TPM, gardée en mémoire volatile — peut le déchiffrer, via un KEM hybride ML-KEM-768 + X25519 qui résiste même si l'un des deux composants cède. Le système échoue fermé par choix : toute vérification ratée rejette la requête plutôt que de risquer un déchiffrement hors zone.

🛠 Dev
• Les agents de codage rendent accessibles des projets qui prenaient des années
  Dan Luu montre, exemples à l'appui, comment des agents de codage permettent de retenter en quelques heures des projets ambitieux autrefois hors de portée — réécriture partielle de Postgres ayant révélé de vrais bugs, moteur regex et fork de ripgrep maison, zstd réimplémenté à 99% de réussite aux tests pour environ 1$. La condition : tester, fuzzer et benchmarker sérieusement, sinon l'ambition tourne au code fragile — le gain se paie en vérification, pas en gratuit.
• Un module noyau débloque le débit matriciel des RTX 3000 avant le pilote NVIDIA
  Sans toucher au pilote lui-même, ce module Linux débloque le débit FP16/BF16/TF32 bridé sur les cartes RTX 3000 — jusqu'à +80% en BF16 et +36% en préremplissage LLM selon les modèles. L'intérêt dépasse le détournement gaming : l'approche (reset FLR, relecture post-suspension, compatible passthrough VFIO) évite de tout repatcher à chaque mise à jour pilote, un cas d'étude d'administration système bas niveau.
