# Digest envoyé — 2026-09-29

## Message

🗞 Veille — mardi 29 septembre

🤖 IA / Agents
• NVIDIA sécurise les agents IA au niveau du silicium avec OpenShell et Sentry — OpenShell trace et contraint l'activité d'un agent en runtime ; Sentry, un chien de garde matériel sur les DPU BlueField-4, peut le mettre en quarantaine en quelques millisecondes. Plus de 100 partenaires annoncés (Anthropic, Microsoft, Cisco...) — un garde-fou déporté hors de l'agent, non contournable par un bug logiciel ou une injection de prompt.
• Cloudflare repense sa CLI pour qu'elle soit pilotée par des agents — "cf" remplace progressivement Wrangler : plus de 3000 opérations d'API contre 280, sortie JSON par défaut, recherche en langage naturel intégrée. Motif chiffré : l'usage agentique de Wrangler est passé de marginal à 48% des appels en un an, avec presque 2x plus de commandes distinctes par jour que les humains.

🏗 Archi
• Sans exigences de qualité explicites, un agent de code produit une architecture fragile — Cinq usages concrets pour cadrer un agent de code : documenter du legacy non documenté, détecter les violations de frontières DDD, auditer la sécurité automatiquement, générer des templates respectant des contraintes non-fonctionnelles explicites. Déplace le travail de l'architecte vers la formalisation de ces contraintes en amont plutôt que leur contrôle en aval.

🧱 System design
• Cloudflare fait tourner du Rust natif avec Tokio dans un Worker single-thread — Nouvelle cible Emscripten : JSPI mappe les opérations bloquantes vers des promesses JS, LocalEventLoop découpe le runtime Tokio pour un ordonnancement coopératif sans bloquer la boucle hôte. Preuve de concept : un serveur Minecraft persistant tournant sans modification dans un Durable Object.

🛠 Dev
• Postgres AT TIME ZONE 'UTC' ne fait pas ce qu'on croit — L'opérateur convertit silencieusement un timestamptz en timestamp sans fuseau — un type déjà déconseillé par le wiki Postgres. Conséquence : une comparaison entre les deux types renvoie toujours false, et l'addition d'un intervalle change de résultat selon le fuseau de la session.

📡 Radar — ThoughtWorks Vol 34
• Server-driven UI — Trial
  Le rendu mobile est délégué à un conteneur générique piloté par des données envoyées par le serveur, pour déployer sans repasser par les cycles de review des app stores. Le radar note un retour en grâce net, porté par Airbnb et Lyft — à réserver aux zones les plus dynamiques d'une appli, pas comme remplacement généralisé de l'UI.
• Browser-based component testing — Trial
  Le radar déconseillait ces tests jusqu'ici, jugés trop lents et instables. Avec Playwright, l'écart de performance est devenu mineur et la stabilité meilleure que les environnements émulés type jsdom — un revirement de position assez rare pour être noté.
• HTML Tools — Assess
  Empaqueter un utilitaire en un seul fichier HTML autonome, exécutable directement dans un navigateur sans binaire ni gestionnaire de paquets. Les outils agentiques facilitent la création de petits scripts ad hoc, mais leur partage restait un point de friction — ce fichier unique le résout, moyennant le risque d'exécuter un fichier non fiable, limité par le bac à sable du navigateur.
