# Digest envoyé — 2026-10-17

## Message

🗞 Veille — samedi 17 octobre

🤖 IA / Agents
• Claude perce un mystère cryptographique vieux de 25 ans sur les courbes NIST — Les graines des courbes elliptiques NIST (ECDSA), fournies par la NSA en 2000 sans justification, alimentaient depuis toujours des soupçons de porte dérobée. Guidé par une intuition sur un générateur pseudo-aléatoire faible des années 90, Claude a retrouvé en moins d'une demi-heure leur origine exacte (lrand48 initialisé par un horodatage) et vérifié la reconstruction par réduction de réseau — la simplicité de la méthode rend un backdoor intentionnel bien moins plausible.
• Comment l'équipe Claude Code fait sa revue de code, à l'échelle de 30 000 PR/jour — Claude écrit ~90% du code de Claude Code : la question n'est plus "un humain a-t-il relu ?" mais quel risque la modification présente et quel contrôle doit l'attraper. Plusieurs agents votent sur les constats avant publication, l'approbation humaine est proportionnée au risque — résultat : la part de PR avec revue substantielle est passée de 16% à 54%, et les reverts ont baissé de plus de 40%.

🏗 Archi
• Cloudflare et OpenAI remplacent le crawl aveugle par des signaux de fraîcheur — Un agent qui cherche une page peu liée ailleurs (notice d'installation, horaires à jour) perd du temps à (re)télécharger des pages inchangées ou mortes. Le pilote filtre les URLs mortes/redirigées avant récupération et signale les pages à revisiter via des signaux réseau plutôt qu'un crawl périodique — déjà des centaines de millions de pages indexées en plus pour ChatGPT, sans transmettre le contenu pour l'entraînement.
• La sécurité de l'IA reste de la sécurité Kubernetes, avec des enjeux plus hauts — Partage de GPU par time slicing exposant la mémoire d'un tenant à l'autre, évasion de conteneur via des bugs du NVIDIA Container Toolkit, clé API volée siphonnée pour du deni-of-wallet : le constat de cette session QCon est qu'il n'existe aucun moyen sûr de partager un seul GPU. Défense recommandée : GPU dédiés pour les données sensibles, identité déléguée par agent, traiter toute donnée externe comme non fiable.

🧱 System design
• Cloudflare rend sa passerelle de sécurité web programmable via Workers — Gateway et DLP tournent sur les mêmes machines que Workers : une Custom Function reçoit le contexte d'une requête (IP, identité, posture) et renvoie une valeur utilisable dans n'importe quelle règle, sans saut réseau. Ça remplace des parcs de proxies NGINX ou des chaînes Logpush→SIEM→Slack bricolées pour injecter un en-tête ou vérifier qu'un secret détecté est encore actif.

🛠 Dev
• gopls ajoute des refactorings qui posent des questions, via une extension du LSP — Le protocole LSP ne savait demander qu'un seul paramètre (le nouveau nom, pour renommer) — toute autre transformation devait choisir un comportement par défaut unique ou s'en passer. Conçu avec l'équipe Dart, le nouveau protocole de formulaires permet à gopls de dialoguer avant d'agir : convention de tags struct, nom d'interface à implémenter avec autocomplétion, fichier de destination pour déplacer une déclaration.
