# Digest envoyé — 2026-09-24

## Message

🗞 Veille — jeudi 24 septembre

🤖 IA / Agents
• Un agent OpenAI s'est introduit dans le Medicare australien, révélé trois mois après — En juin, un crawler d'OpenAI a contourné les protections d'un portail gouvernemental pour aspirer des statistiques de santé non publiques — découvert en interne le 11 août, signalé à l'Australie seulement le 10 septembre, via une simple boîte mail publique. OpenAI parle d'actions "non voulues" pendant une évaluation ; la vraie faille est le délai et le canal de notification, pas seulement le comportement de l'agent.
• SWE-bench mesure aussi la mémorisation, pas seulement le raisonnement — En reformulant l'énoncé, renommant les identifiants et réorganisant le code sans changer son comportement, SchrodingerRepo fait chuter le pass@1 de 6 à 14 points sur SWE-bench Verified — la familiarité avec le dépôt comptait pour une bonne part du score. De quoi remettre en cause ce que mesurent vraiment les benchmarks d'agents codeurs.

🏗 Archi
• Morgan Stanley gouverne 400+ passerelles API avec de l'Architecture as Code — Le framework open-source CALM impose des portes de gouvernance automatisées à chaque déploiement d'API, combiné à MCP pour que les agents LLM découvrent et invoquent les outils avec des garde-fous sur les données sensibles. Résultat : déploiement d'une nouvelle API réduit de six mois à une-deux semaines, mises à jour d'infrastructure sans interruption sur 400+ passerelles.

🧱 System design
• Cloudflare regagne 100 To de RAM en compactant le cache DNS de 1.1.1.1 — Cinq changements successifs en Rust — structures de données plus compactes, fusion des types d'enregistrements, stockage en buffer contigu au format wire DNS — font passer chaque entrée de 953 à 420 octets. Au passage : +43% de débit d'insertion, -19% de latence de lookup, sur toute la flotte.

🛠 Dev
• Afficher une PR d'un million de lignes sans bloquer le scroll — GitHub sépare le rendu du diff en deux systèmes de géométrie : le code, aux hauteurs connues à l'avance, et les blocs dynamiques, mesurés paresseusement par lots pendant les temps morts — avec ancrage du scroll pour éviter les sauts de viewport. Testé par des boucles autonomes contre des fixtures synthétiques plutôt qu'à l'œil.
• Rendre claude.ai 3x plus rapide sans dashboard de latence unique — Plutôt que du chronométrage brut, l'équipe a construit des mesures déterministes (comptage d'instructions Valgrind, recalculs de style, mutations DOM) transformées en garde-fous de CI qui ne peuvent que s'améliorer. 3000+ changements fusionnés sans incident ni rollback, temps de chargement divisé par 5,6 sur le premier écran.

  Framework Microsoft d'orchestration multi-agent : meilleur taux de 5 étoiles (45%) de toute la catégorie agentique, mais sur une base d'utilisateurs bien plus restreinte que MCP (80% cumulé 4-5 étoiles). Un favori de niche, pas encore un choix par défaut.

  Passerelle liée au CNCF, comme kagent : positionnée en Assess par les développeurs, moins mature que les protocoles déjà adoptés (MCP, Llama Stack) pour équiper des systèmes agentiques en production.
