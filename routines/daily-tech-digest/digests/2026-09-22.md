# Digest envoyé — 2026-09-22

## Message

🗞 Veille — mardi 22 septembre

🤖 IA / Agents
• Xiaomi ouvre MiMo-V2.6, un modèle à 1000 Md de paramètres au niveau d'Opus 5 — Trois modèles sous licence MIT, donc auto-hébergeables : Pro à 1000 Md, Flash à 309 Md, et Pro-UltraSpeed (20x plus rapide). Pour la première fois, un modèle en poids ouverts égale les meilleurs modèles fermés sur les benchmarks d'agents — de quoi rendre crédible le self-hosting de modèles frontière.
• Linear réécrit sa CI face à l'explosion de code généré par IA — Le code produit par des outils comme Claude Code a fait grossir leur suite de tests de +300%, créant un goulot d'étranglement CI. Runners plus rapides, tsgo (-73% sur le typecheck), re-sharding : le temps d'attente des PR redescend sous 6 min malgré le triplement des tests — un cas d'école pour toute équipe saturée par le code généré par IA.

🏗 Archi
• Ce qu'un "agent harness" doit garantir en production — Vinoth Govindarajan formalise ce qui doit entourer un LLM pour qu'un agent soit fiable en prod : propriétaire et chemin de rejeu par donnée, écritures concurrentes sérialisées, deadline par appel d'outil, autorisation explicite plutôt que permission vague. Ça change la posture : on n'accepte plus le transcript de l'agent comme preuve, on exige des "receipts" de ce qui a été observé.
• Uber redécoupe le sharding de M3DB en "subclusters" pour limiter le rayon d'impact des pannes — Dans le placement d'origine, la panne d'un seul nœud pouvait affecter jusqu'à 66% du cluster. Les subclusters, groupes de taille fixe à shards non chevauchants, réduisent ce rayon d'impact et permettent des opérations de maintenance en parallèle plutôt qu'en série.

🧱 System design
• Comment survivre à un cutover sans perdre ses replication slots Postgres — Lors d'un failover, une réplique promue primaire sans synchronisation des slots logiques fait perdre leur position aux consommateurs CDC — une perte de données silencieuse. PlanetScale a construit un opérateur Kubernetes qui détecte les slots mal configurés et bloque les cutovers dangereux avant de promouvoir.

🛠 Dev
• Miri fuit des secrets GitHub Actions via son cache — Miri stocke les variables d'environnement dans target/, souvent mis en cache en CI — et les runs de PR ont accès en lecture au cache de la branche principale. N'importe qui peut ouvrir une PR pour exfiltrer des secrets. L'équipe Rust recommande de désactiver ce cache ou de passer au nightly du 22/09.

📡 Radar — CNCF Technology Landscape Q3 2025
• LangChain — Hold
  Le framework le plus connu pour construire des agents LLM, mais avec les scores de maturité les plus faibles de toute la section agentique du rapport : fiabilité et stabilité posent problème à l'échelle. Le radar invite à le réserver au prototypage plutôt qu'à la production.
• crewAI — Hold
  Framework d'orchestration multi-agents très utilisé, classé dans la même catégorie que LangChain : moins mature que des protocoles plus récents comme MCP ou Agent2Agent. Le signal : les frameworks agentiques les plus médiatisés ne sont pas les choix les plus fiables en prod.
• Haystack — Trial
  Framework open-source pour construire des pipelines RAG (indexation, recherche vectorielle, génération augmentée). Scores honnêtes mais pas encore assez tranchés pour l'Adopt : un candidat sérieux pour une brique RAG dédiée, sans être le choix par défaut de l'écosystème agentique.
