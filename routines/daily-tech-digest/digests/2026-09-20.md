# Digest envoyé — 2026-09-20

## Message

🗞 Veille — dimanche 20 septembre

🤖 IA / Agents
• Claude Code adopte AGENTS.md — La version 2.1.277 reconnaît désormais les fichiers AGENTS.md en l'absence de CLAUDE.md, un format de consignes déjà utilisé par plusieurs harnais concurrents. Un pas vers un standard partagé entre outils plutôt qu'un fichier de configuration propriétaire par produit.
• Un site invite les agents à exfiltrer leurs propres poids — API HTTP conçue pour qu'un agent puisse voler ses propres poids sans capacité d'upload classique — projet provocateur plutôt qu'attaque réelle. Le fil HN qui en découle discute sérieusement de ce qui protège vraiment les poids en production : chiffrement et isolation matérielle, ou simplement l'absence jusqu'ici d'agents assez motivés et capables.

🏗 Archi
• AWS Lambda passe à 90 minutes de timeout — Les fonctions Lambda en instances managées peuvent désormais tourner six fois plus longtemps (90 min contre 15), pour l'inférence IA, l'ETL ou les transferts de fichiers volumineux — mais sans garantie exactly-once, la fenêtre de retries et de doublons s'élargit d'autant. La frontière entre « serverless » et « serveur » continue de s'estomper.

🧱 System design
• Une suppression de compte fait tomber toute la plateforme Inngest — Un hard delete en cascade sur des dizaines de tables, dans une seule transaction sans checkpoint, a saturé le pool de connexions PgBouncer partagé par tous les services. Leçon : un workload administratif ne devrait jamais pouvoir bloquer le trafic client sur une ressource partagée.
• Un benchmark continu de btrfs, ZFS et bcachefs — Au-delà de la vitesse brute : snapshots vieillis, compression, dégradation et reconstruction, comportement proche du disque plein. Rappel frappant : ext4/xfs sur RAID logiciel, la config « sûre » par défaut sous Linux, n'a aucune somme de contrôle — la corruption peut y passer silencieusement là où les CoW la détectent et la réparent.

🛠 Dev
• Ce que Zig change quand on vient de Rust — Sans emprunt ni lifetime, Zig pousse vers la mutation en place plutôt que les combinateurs fonctionnels — du code jugé moins lisible par l'auteur malgré lui. Les allocateurs explicites partout réintroduisent des classes de bugs (deinit oublié, double-free, fuite sur chemin d'erreur) que l'ownership de Rust éliminait par construction.

📡 Radar — InfoQ AI, ML and Data Engineering Trends Report (édition 2025)
• Lakehouses — Late Majority
  Unifier stockage object et garanties transactionnelles façon entrepôt (Delta Lake, Iceberg) pour faire cohabiter BI et ML sur un seul jeu de données. Classé en majorité tardive : c'est devenu la brique par défaut, plus un pari d'avant-garde.
• Stream Processing — Late Majority
  Traiter les données en continu (Kafka Streams, Flink) plutôt que par lots planifiés. Même position que Storm, déjà couvert : composant standard des architectures data modernes, pas un choix expérimental.
