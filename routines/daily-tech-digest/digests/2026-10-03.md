# Digest envoyé — 2026-10-03

## Message

🗞 Veille — samedi 3 octobre

🤖 IA / Agents
• Un agent IA peut devenir un vecteur de ver informatique — Le cryptographe Matthew Green relève qu'un agent compromis plus un canal partagé (cache de paquets, email, Slack, documents) suffisent à reproduire les ingrédients d'un ver. Remplacez le bac à sable d'un run d'entraînement par un agent personnel déployé en continu (type Muse), et l'isolation ne protège plus de rien.
• Le noyau Linux croule sous les rapports de sécurité générés par IA — Greg Kroah-Hartman : l'équipe sécurité du noyau émet désormais ~13 CVE par jour, en bonne partie nourris par des rapports LLM de piètre qualité. Rust promu comme parade structurelle (élimine la classe de bugs mémoire/verrous à la compilation) ; les patches IA sont désormais interdits dans drivers/staging, terrain d'apprentissage réservé aux humains.

🏗 Archi
• La librairie de composants UI partagée devient jetable, pas le design system — Un modèle pointé sur un design system solide régénère à la demande l'essentiel d'une UI standard : maintenir un package de composants versionné coûte plus qu'il ne rapporte. Ce qui devient précieux : les tokens de design et les tests de non-régression visuelle — la vérification remplace la réutilisation de code.
• Toute entreprise SaaS va devenir un harnais autour d'un modèle — Quand les agents orchestrent le travail en autonomie et que les humains se concentrent sur l'arbitrage à fort enjeu, la compétence centrale de l'entreprise devient la construction du harnais — router les décisions vers les bons experts. Conséquence directe : garder sa maîtrise en interne plutôt que de la sous-traiter à un vendeur.

🧱 System design
• « Rien n'est aussi rapide que ne rien faire » — PlanetScale évite de décoder ce qu'il n'utilise pas — Neki, le routeur de sharding Postgres de PlanetScale, garde les résultats en octets bruts du protocole le plus longtemps possible et ne décode que les colonnes réellement nécessaires (ex. les clés de tri pour un ORDER BY). Des couches optionnelles valent mieux qu'un décodage systématique.
• Cloudflare trace une requête de bout en bout sans changer une ligne de code — Instrumentation automatique (zéro code à changer), propagation W3C traceparent vers l'origine, export OpenTelemetry, règles d'échantillonnage dynamique (1% de base, 100% sur un hôte ciblé). De quoi arrêter de reconstituer le chemin d'une requête à partir de logs séparés.

🛠 Dev
• Rust abandonne les outils hôtes sur Windows 32 bits — i686-pc-windows-msvc et -gnu perdent le compilateur en natif (la stdlib reste) : plus personne ne vend de CPU 32 bits depuis 15 ans, et builder un toolchain 32 bits sur du matériel moderne provoque des crashs. La compilation croisée depuis un hôte 64 bits devient la seule voie restante.
• Go ouvre l'accès direct aux instructions SIMD propres à chaque architecture — Le nouveau package archsimd complète le SIMD portable de Go 1.26 : là où simd expose l'intersection commune entre architectures, archsimd donne accès aux instructions spécifiques au matériel (AVX-512, NEON...), avec des noms sémantiques plutôt que les intrinsics bruts.
