# Digest envoyé — 2026-09-23

## Message

🗞 Veille — mercredi 23 septembre

🤖 IA / Agents
• Opus 5.5, GPT-6 Sol et Luna : la guerre des prix s'intensifie — Anthropic baisse Opus 5.5 de 20% (4$/20$ le million de tokens, cache à 0,20$ soit -60%) le jour même où OpenAI sort Sol et Luna — ce dernier à 0,10$/0,50$, un dixième du prix de Haiku 4.5. Pour les applis agentiques qui tournent en boucle, c'est le coût par appel d'outil qui bascule, pas les benchmarks.

🏗 Archi
• Stripe expose son checkout aux agents via WebMCP — Plutôt que de laisser un agent deviner le HTML, Stripe expose des outils MCP côté client, révélés progressivement selon l'état du formulaire et branchés sur la même logique métier que l'UI humaine. Résultat mesuré : -42% de tokens, -39% de temps, -38% d'appels d'outils par transaction.
• SAML, un fractal de mauvais design — Signature wrapping, différentiels de parseur XML, signatures "enveloped" : des décennies de vulnérabilités qui ne sont pas des bugs d'implémentation mais des choix de design qui ossifient le protocole. L'argument pour migrer vers OIDC plutôt que corriger SAML à la marge.

🧱 System design
• Cloudflare dompte enfin le header Vary — Trois modes par header déclaré dans Vary — normaliser, passthrough ou bypass — pour arbitrer entre cache massif et contenu correct sans dupliquer la logique de l'origine.
• Une URL isolée par branche Git pour tester les agents en sécurité — Chaque branche obtient sa propre URL, sa config, ses Durable Objects et son observabilité — de quoi tester des workflows complets sans toucher à la prod, alors que les agents génèrent du code plus vite qu'on ne peut le relire.

🛠 Dev
• Un chemin de validation oublié ouvre une RCE non authentifiée dans WordPress — Dans get_page_template(), le paramètre pagename construit un nom de fichier sans passer par validate_file() — contrairement à un chemin voisin qui l'appelle. Path traversal vers un fichier PHP local, RCE conditionnelle, corrigé dans la 7.1.2 et rétroporté jusqu'à la 4.7.

📡 Radar — ThoughtWorks Technology Radar Vol 34
• Skills as executable onboarding documentation — Assess
  Un skill /_setup combine script et sémantique exécutée par LLM pour les étapes non scriptables, en tenant compte de l'état réel du code et de l'environnement. Contrairement à une doc statique, une doc exécutable révèle sa péremption bien plus tôt.
• Toxic flow analysis for AI — Assess
  Quand un agent cumule accès à des données privées, exposition à du contenu non fiable et capacité à communiquer vers l'extérieur (la "lethal trifecta"), une instruction cachée dans ce contenu suffit à exfiltrer des données. Le radar recommande d'analyser le graphe de flux d'un système agentique pour repérer ces chemins avant qu'ils ne soient exploités.
