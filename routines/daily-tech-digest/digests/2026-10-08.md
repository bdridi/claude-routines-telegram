# Digest envoyé — 2026-10-08

## Message

🗞 Veille — jeudi 8 octobre

🤖 IA / Agents
• Claude Haiku 5.5, le petit modèle qui coûte 75% moins cher — Anthropic sort son Haiku le plus rapide à ce jour, avec un réglage d'effort de raisonnement ajustable — une première pour la gamme Haiku. Coût moyen en baisse de ~75% vs Haiku 4.5 (jusqu'à -90% sous 100k tokens) : pensé comme sous-agent à grand volume (résumés, classification, requêtes) aux côtés d'Opus ou Sonnet, pas pour le codage agentique complexe.
• GPT-6 arrive pour tout le monde, avec une UI qui se compose elle-même — ChatGPT choisit désormais texte, graphiques, boutons ou formulaires selon la question plutôt que de tout rendre en texte brut — déployé à 1,2 milliard d'utilisateurs hebdomadaires. Aucun chiffre de benchmark ni détail de modèle publié : l'annonce porte sur l'expérience, pas sur la capacité sous-jacente.

🏗 Archi
• Garder l'ordre par session sur Kafka, sans une partition par session — Un routage à deux niveaux — workers de dispatch par hachage, puis une goroutine dédiée par session qui sérialise ses propres messages — évite de faire exploser le nombre de partitions. Retries en place, commit par watermark contigu : plus de 40M messages traités en production sans violation d'ordre observée.
• Cloudflare sépare la preuve du jugement dans son harnais d'agents de sécurité — Face à un agent unique qui confondait hypothèse et preuve, Cloudflare bascule vers une reconnaissance déterministe en code, un paquet de preuves versionné que les agents doivent citer, et des spécialistes aux sorties typées. Le principe généralisable : jamais de frontière de sécurité posée dans un prompt.

🛠 Dev
• GitHub mise sur un classifieur pour détecter les secrets non structurés — Révoquer un secret exposé prend 40 jours en moyenne ; un ModernBERT affiné évalue chaque candidat dans son contexte de code en moins de 2ms, directement sur le chemin du push. « La prévention scale avec le calcul, la remédiation scale toujours avec les gens. »
• Chrome réécrit son décodeur JPEG XL en Rust plutôt que de sandboxer le C++ — Plutôt que patcher la bibliothèque de référence libjxl, Chrome 155 embarque jxl-rs, une réimplémentation complète en Rust avec SIMD sans code unsafe (target_feature_11). La sandbox devient une protection secondaire, pas la seule ligne de défense contre les bugs mémoire des décodeurs d'images.
