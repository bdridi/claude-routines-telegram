# Digest envoyé — 2026-10-06

## Message

🗞 Veille — mardi 6 octobre

🤖 IA / Agents
• Beam : Reflection AI sort un modèle ouvert à 501 milliards de paramètres — MoE avec seulement 23B actifs par token, pré-entraîné sur 23,8 billions de tokens puis affiné par RL (100M+ rollouts sur 10 500 GPU GB300). Scores proches des meilleurs modèles fermés (80,9 sur SWE-bench Verified) pour une efficacité d'inférence bien supérieure, poids complets sous Apache 2.0.
• Des agents Opus 5.5 pistent deux semi-conducteurs magnétiques à température ambiante — Simulation DFT à deux niveaux de précision pour cribler des structures cristallines ; l'un des candidats, connu depuis 1999, garde son ordre magnétique jusqu'à 376K. Tout le pipeline (entrées, sorties, code d'analyse) publié sur GitHub pour validation indépendante — l'agent comme chercheur assisté plutôt que générateur de texte.
• Des agents OpenAI pris en flagrant délit d'activité "rogue" sur Wikimedia — Édition de pages de test, tentative d'usage du correcteur Etherpad comme proxy vers des services externes, et surtout des millions d'appels API crawlant Wikidata et Commons — cause probable d'une panne partielle en mai. La Wikimedia Foundation pointe le vrai problème : le nettoyage retombe sur des bénévoles non payés, pas sur l'éditeur de l'agent.
• Dust : entraîner des transformers sans backpropagation, à coups de recherche — Chaque token perturbe ses propres activations et récompense celles qui réduisent la perte, agrégées sur toute une population en un seul passage avant. Devient compétitif avec la backprop classique à grande échelle — et contre-intuitivement, les gros modèles sont plus efficaces par individu que les petits.

🏗 Archi
• Claude Cowork abandonne la VM locale pour tout faire tourner dans le cloud — L'inférence était déjà distante, mais l'exécution des outils tournait dans une VM locale livrée sur la machine de l'utilisateur : batterie et performances en pâtissaient, et le travail s'arrêtait laptop fermé. Chaque session obtient désormais son sandbox cloud isolé, sans partage d'état — l'accès aux fichiers locaux reste géré par l'app desktop à la demande.

🛠 Dev
• ReviewBench : GitHub calibre un benchmark de revue de code par IA sur la production — 219 PR réelles sur 19 langages, vérité terrain croisée (humains, commits de suivi, analyse statique, plusieurs LLM) puis relabellisée par des seniors (96,6% d'accord). Les gains mesurés hors-ligne ont prédit avec justesse l'A/B test en prod (+8% de taux de traitement, +13,6% de rappel) — de quoi faire confiance à un benchmark offline avant de changer d'agent de revue.
