## Message

🗞 Veille — mardi 20 octobre

🤖 IA / Agents
• Mon obituaire pour la programmation — Simon Willison relaie l'essai de Jeremy Scheff sur ce que les agents de code retirent au métier : le plaisir de résoudre soi-même le casse-tête disparaît quand l'agent fait le travail. Un angle utile pour nommer ce qu'on perd, pas seulement ce qu'on gagne, en déléguant.
• Self-HPO : co-optimiser le harnais et le modèle d'un agent de code — Plutôt que régler le harnais une fois puis entraîner le modèle dessus, Self-HPO alterne : la politique analyse ses propres échecs pour revoir le harnais, et les tâches qui restent dures nourrissent le round de RL suivant. Sur SWE-bench, le taux de résolution de Qwen3.5-35B passe de 57,8% à 64,8% — la leçon : régler scaffolding et modèle séparément laisse de la performance sur la table.

🏗 Archi
• Des microservices aux agents — Les systèmes agentiques déplacent la décomposition du flux de contrôle — fixée à la conception avec les microservices — vers des décisions prises à l'exécution, et les pannes deviennent des dérives silencieuses de qualité plutôt que des erreurs explicites. Conséquence concrète : budgets de latence, limites d'itération, repli déterministe, et une observabilité qui trace les décisions prises, pas seulement la latence et les erreurs.

🧱 System design
• Comment Cloudflare a réduit sa facture d'inférence de 68% — Le coût par revue de code IA avait doublé (tokens par revue triplés, bascule vers des modèles Anthropic plus chers). En rendant le préfixe de prompt partagé réellement cacheable entre dépôts (hit rate de 14-26% à 91-99,5%), en parallélisant les lectures et en retirant les appels d'outils inutiles, l'équipe retombe à 0,77$ par revue. La leçon générale : vérifier que le cache sert vraiment avant d'incriminer le modèle.
• Stripe fait tourner ses expériences anti-fraude par des agents — Agentic MLE laisse des agents porter un cycle d'expérimentation ML — exploration des données, entraînement, debug — sur l'infra existante, avec revue humaine aux points de décision. La meilleure idée testée (une config de stochastic weight averaging) améliore le recall du moteur anti-fraude Shield de plus de 8%, et des optimisations séparées font passer une epoch de 24h à 4,8h sur 11 milliards de transactions.

🛠 Dev
• La concurrence structurée devient finale dans JDK 28 — JEP 543 fige l'API StructuredTaskScope après sept rounds de preview, sans changement depuis JDK 27 : le code existant n'a qu'à recompiler sans --enable-preview. Elle remplace le couple ExecutorService/Future, où un échec ne remonte qu'au get() et où des threads peuvent survivre à leur parent, par un point de jonction unique qui annule proprement les sous-tâches restantes — utile dès qu'on fait du fan-out.
• Continuer une session Copilot de l'app vers VS Code — Une session d'agent Copilot lancée dans l'app se reprend dans VS Code avec sa conversation, son plan, son diff et son worktree intacts. L'intérêt : laisser l'agent abattre le gros du travail, puis reprendre la main pour relire, corriger et lancer les tests sans tout recommencer.
