# Digest envoyé — 2026-09-25

## Message

🗞 Veille — vendredi 25 septembre

🤖 IA / Agents
• AgentKernel : un OS natif pour la confiance dans les agents — Les agents LLM traversent des frontières de confiance sans garde-fou OS : contenu non fiable, instructions privilégiées et outils se mélangent dans le même contexte. AgentKernel impose une médiation obligatoire jusqu'au filtrage des appels système via eBPF — la sécurité devient un multiplicateur de capacités plutôt qu'un frein.
• DeepMind chiffre la mémoire des assistants IA côté cloud — Les clés de chiffrement restent sur l'appareil, même si la mémoire de l'assistant est stockée et traitée côté cloud pour rester dispo sur plusieurs appareils. Ça résout le dilemme habituel : le calcul est côté serveur, mais la confidentialité reste comme si les données n'avaient jamais quitté l'appareil.

🏗 Archi
• Edge computing modulaire pour du SaaS multi-tenant sur Cloudflare Workers — Retour d'expérience sur des patterns de modularité qui isolent les tenants sans dupliquer l'infra à l'échelle. Utile pour qui pousse une architecture multi-tenant au-delà d'une poignée de clients.

🧱 System design
• Cloudflare détaille une fuite de données cross-tenant dans Containers — Des chercheurs ont trouvé un moyen d'accéder aux données résiduelles de charges de travail précédentes sur le même hôte. Post-mortem complet, faille et correctif à l'appui — une référence sur l'isolation multi-tenant en calcul partagé.

🛠 Dev
• Quand le chat est la mauvaise interface pour l'IA — GitHub plaide pour des interfaces en canevas plutôt qu'en chat pour certaines tâches de dev assisté par IA : le chat linéaire cache mal les changements d'état complexes qu'un agent de code produit.
• Go expérimente une API SIMD indépendante du matériel — Go 1.27 introduit une API SIMD portable qui ne dépend pas d'une architecture CPU spécifique. Ouvre la voie à du code vectorisé performant sans sacrifier la portabilité, jusqu'ici le compromis habituel en Go.

📡 Radar — ThoughtWorks Vol 34
• Évaluation des LLM par entropie sémantique — Assess — Détecte les hallucinations en mesurant la variation de sens des réponses plutôt que leur variation de mots. Prometteuse sur des tâches inédites, mais encore une piste de recherche à explorer plutôt qu'un outil à brancher en prod.
• Réduction de la dérive architecturale avec des LLM — Assess — Combine des outils déterministes (ArchUnit, Spring Modulith) pour détecter les violations structurelles avec des LLM pour les corriger ; les correctifs générés doivent rester petits et vérifiés.
• Environnements de RL pour agents — Assess — Environnements d'entraînement où un agent LLM reçoit récompenses et pénalités à chaque action. Réservé pour l'instant aux labos et aux équipes qui construisent leurs propres agents spécialisés.
