# Digest envoyé — 2026-10-11

## Message

🗞 Veille — dimanche 11 octobre

🤖 IA / Agents
• AgentGarten : des « mondes de code » pour entraîner des agents sans tout coder en dur — Un moteur de jeu génère la géométrie d'une scène, un rendu neuronal distillé par un nouveau procédé (Adversarial Forcing) la transforme en image réaliste pour l'agent — il suffit d'une image ou d'un texte pour qu'un agent codeur construise le monde. Sur cinq scénarios testés (cache-cache, pont, troupeau...), les agents progressent nettement sur plusieurs tours, sans ré-entraîner le renderer à chaque nouveau monde.
• Talorys : un assistant IA personnel entièrement logé sur le tier gratuit Cloudflare — Pages devant un Worker privé relié par service binding, mémoire et tâches dans un Durable Object SQLite, rappels pilotés par les alarmes du Durable Object plutôt que par un serveur toujours actif. Un patron d'architecture complet pour héberger son propre agent sans louer la moindre VM.

🏗 Archi
• Cockroach Labs fait tourner ses agents de code comme un hôpital — Des « Fellows » écrivent le code, un « Review Attending » distinct relit, une « Discharge Nurse » audite avant fusion — les humains tranchent et consignent leurs décisions dans un journal de précédents. En cinq mois : plus d'un million de lignes livrées, 7 retours arrière, un support IBM Db2 ajouté en deux jours pour 4172$ de tokens contre 9 mois et 160k$ en 2024 pour un cas Oracle comparable.
• Les unikernels, c'était dur — au passé — Un unikernel fait de l'application elle-même le système, sans shell ni espace utilisateur : surface d'attaque minimale, mais porter les bibliothèques manquantes était jusqu'ici dissuasif. Les agents de code changent le calcul en se chargeant de ce portage — de quoi rendre l'architecture crédible hors des niches de recherche.

🧱 System design
• Cloudflare Traces : la couche proxy devient lisible comme une trace OpenTelemetry — Règles de sécurité, transformations, décisions de cache, routage, exécution Worker, traitement par l'origine : chaque étape devient un span avec durée et résultat, sans instrumentation à écrire. Sur un exemple de cache miss, la trace révèle que 527ms sur 539ms partent dans l'attente de l'origine — exactement ce qu'un simple log n'aurait pas montré.
• Cloudflare K2 : un stream d'événements durable posé sur du stockage objet — Plutôt qu'un cluster Kafka à opérer, un log partitionné et durable au-dessus de R2, né comme simple buffer d'ingestion pour des pipelines internes avant de devenir un produit à part entière. Latence de production annoncée à ~1s en p99 : l'arbitrage assumé face à des solutions plus rapides mais plus lourdes à exploiter.

🛠 Dev
• 500 milliards de tokens pour décompiler un FPS avec des agents — Le problème n'était pas de faire tourner le code recompilé mais de garantir qu'il faisait vraiment la même chose : la solution a été un oracle qui compare chaque fonction recompilée octet par octet au binaire d'origine. Résultat : 99% des fonctions présentes, 83% identiques au bit — un signal PASS/FAIL binaire qui a permis à des modèles moins chers de contribuer utilement.
